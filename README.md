# AWS Call Center Infrastructure Migration

## Overview
This project demonstrates the migration of an on-premises call center infrastructure to Amazon Web Services (AWS).
The infrastructure was designed following AWS best practices to improve scalability, high availability, security, monitoring, and backup management.

## Project Objectives
- Migrate an on-premises call center infrastructure to AWS
- Improve system availability
- Implement scalable architecture
- Secure cloud resources
- Configure monitoring and alerting
- Implement automated backup strategy

## AWS Services Used
- Amazon EC2
- Amazon VPC
- Amazon RDS (MySQL)
- Amazon S3
- Application Load Balancer (ALB)
- Auto Scaling Group
- Amazon CloudWatch
- AWS Backup
- IAM
- Security Groups
- Route Tables
- Internet Gateway
